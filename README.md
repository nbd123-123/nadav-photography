# נדב בן דוד — אתר תיק עבודות

אתר סטטי: `index.html`, `css/style.css`, `js/main.js`, ותמונות בתיקייה `img/`. אין שלב build.
לצפייה מקומית פותחים את `index.html` בדפדפן.

## החלפה לתמונות ברזולוציה מלאה

1. מייצאים כל תמונה כ-JPEG, צלע ארוכה 2500px, איכות 80–85.
2. שומרים אותן ב-`img/` (ותמונות מירקה ב-`img/fashion/`) **באותם שמות קבצים בדיוק**, ודורסים את הישנות (למשל `01.jpg`, `fashion/IMG_0458.jpg`). אין צורך לגעת בקוד.
3. אם שיניתם חיתוך של תמונה בגלריה (היחס בין רוחב לגובה), עדכנו את `width` ו-`height` שלה ב-`index.html` ליחס החדש. המספרים מסמנים רק את היחס, לא את הגודל, ומונעים מהעמוד "לקפוץ" בזמן הטעינה.
4. תמונה חדשה בגלריה: מעתיקים שורת `<figure>` קיימת, ומעדכנים בה את `src`, `alt` (תיאור קצר בעברית), `width`/`height` והמספר.

## פרסום בחינם

### Netlify (הכי פשוט)
1. נרשמים ל-[netlify.com](https://www.netlify.com).
2. ב-**Sites**, גוררים את כל תיקיית הפרויקט אל אזור ה-Drop (‏Netlify Drop).
3. מקבלים כתובת כמו `https://something.netlify.app`. את השם אפשר לשנות ב-**Site configuration → Change site name**.
4. לעדכון: גוררים שוב את התיקייה דרך **Deploys**.

### GitHub Pages
1. יוצרים ריפו חדש ב-GitHub ומעלים אליו את הקבצים (`git push`, או **Add file → Upload files** באתר).
2. בריפו: **Settings → Pages**. ב-**Source** בוחרים **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, ושומרים.
3. אחרי דקה-שתיים האתר עולה בכתובת `https://<שם-משתמש>.github.io/<שם-ריפו>/`.

### אחרי הפרסום
ב-`index.html` מחליפים את `og:image` לכתובת מלאה (למשל `https://something.netlify.app/img/01.jpg`). בלי זה, וואטסאפ ופייסבוק לא יציגו תמונה בתצוגה המקדימה של הקישור.
